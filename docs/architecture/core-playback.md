# 核心播放架构

Silent Nocturne 的核心播放链路分为共享领域层、Electron 主进程边界、preload API 和 renderer 协调层。该拆分的目的，是让树操作与播放规则可独立测试，同时限制 renderer 对本地文件和 Electron 能力的访问。

## 音乐树与节点身份

分类歌单和当前播放队列都使用 `MusicTreeNode`：

- `TrackNode` 保存独立节点 ID、文件名和本地索引路径；
- `PlaylistNode` 保存独立节点 ID、名称和有序子节点；
- 数组顺序同时表示界面顺序和播放展开顺序。

路径标识本地音乐资源，节点 ID 标识该资源在某棵树中的一次出现。队列允许同一路径出现多次，因此当前播放对象始终按节点 ID 定位。

共享领域逻辑位于 `src/shared/domain/`，不依赖 Vue、DOM 或 Electron：

- `music-tree.ts`：遍历、查询、复制、选择、删除、插入和移动；
- `playback.ts`：分类歌单直属播放、队列递归展开和相邻曲目计算；
- `app-state.ts`：可持久化状态的版本化结构。

从分类歌单加入当前队列时，每个节点都会获得新 ID，不保留来源关联。移动节点则保留原 ID，因此移动当前音乐或其祖先不会重启播放；删除当前音乐或其祖先会清空播放状态。

## 进程责任

### 主进程

`src/main/` 负责所有需要本地系统权限的行为：

- 打开系统文件和文件夹选择器；
- 扫描 MP3、FLAC，保留目录层级并裁剪空分支；
- 规范化和比较 Windows 路径；
- 检查文件是否存在并读取音频元数据、内嵌封面；
- 校验并保存版本化应用状态；
- 为已授权媒体签发短期访问令牌并处理流式读取。

文件夹扫描不会跟随符号链接，也不会移动、重命名、修改或删除音乐文件。应用内的删除只更新索引树和应用状态。

### Preload

`src/preload/index.ts` 只通过 `contextBridge` 暴露 `SilentNocturneApi` 中列出的固定业务方法。renderer 无法获得 `fs`、`ipcRenderer`、任意 IPC channel 或通用 Electron API。

### Renderer

Pinia store 位于 `src/renderer/src/stores/app-store.ts`，负责协调：

- 页面、选择、展开和错误提示；
- 调用共享领域函数完成树编辑；
- 调用窄 preload API 完成导入、状态保存和媒体请求；
- 管理当前节点、播放上下文、进度、音量和暂停状态。

真实 `<audio>` 元素由 `PlayerBar.vue` 持有。组件处理媒体事件并把可持久化状态回传给 store，但不拥有队列算法或文件访问能力。

## 受控媒体访问

renderer 播放音乐前，需要先通过主进程检查该路径是否属于本次会话已授权的索引。主进程随后签发高熵、有限时长的媒体令牌，renderer 只能获得如下形式的 URL：

```text
sn-media://audio/<token>
```

URL 不包含本地绝对路径。私有协议 handler 将令牌解析回主进程维护的授权路径，并支持标准单段 `Range` 请求，以便 Chromium 音频元素进行媒体探测和进度跳转。未知、过期或格式错误的令牌不会映射到磁盘文件。

内嵌封面由主进程解析，只接受 JPEG、PNG 或 WebP，并限制为最多 5 MiB。没有可用封面时 renderer 使用统一默认图形。

## 状态持久化

当前状态 schema 版本为 `1`，包含：

- 分类歌单树；
- 当前播放队列；
- 当前音乐节点和播放上下文；
- 播放进度、音量、模式和暂停状态；
- 展开的树节点。

主进程在写入前完整校验 schema、树深度、节点数量、全局 ID 唯一性、绝对路径、播放引用和数值范围。写入使用目标文件同目录的独占临时文件，刷新文件内容后再原子重命名；并发保存按接收顺序串行执行。

如果状态文件缺失，应用使用默认空状态。如果内容损坏或版本不受支持，应用保留原文件、显示警告并使用空状态启动，不会用空状态立即覆盖原内容。

关闭窗口时，主进程先通知 renderer 刷新最后状态，收到完成确认后才真正关闭窗口。重新启动会恢复当前音乐、进度和音量，但无条件保持暂停，避免自动发出声音。

## 验证

纯领域规则、Windows 路径、临时目录扫描、持久化和关键 store 编辑行为由 Vitest 覆盖。常规验证命令：

```bash
pnpm lint
pnpm test
pnpm typecheck
pnpm build
```

真实音频输出、Windows 文件选择器、嵌套拖拽和关闭重启行为仍需在 Electron GUI 中人工验证。
